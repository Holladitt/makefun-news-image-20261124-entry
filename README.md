A program that writes one image summing up the world's news of Tuesday 24 November 2026 to `/output/entry.png`.

## Run

```sh
node main.ts
```

Writes `/output/entry.png` (PNG, at most 1 MiB, at most 1024 by 1024 pixels, deterministic, no network).
